# KAMPUNG RESIK — Portal Digital Terpadu Kelurahan Jatimekar

Landing page resmi penghubung 4 layanan digital warga Kelurahan Jatimekar:
1. **Jalin Jatimekar** (Pelaporan infrastruktur & lingkungan)
2. **Pojok Edukasi UMKM** (Perpustakaan materi & template promosi UMKM)
3. **Dashboard UMKM Ber-NIB Jatimekar** (Direktori informasi UMKM ber-NIB)
4. **Radar Gotong Royong** (Jadwal kebersihan & dokumentasi kerja bakti)

## Cara Deploy ke GitHub & Netlify
1. Push seluruh file ke repository GitHub bernama `kampung-resik`.
2. Buka Netlify -> **Add new site** -> **Import an existing project** -> Pilih GitHub `kampung-resik`.
3. Kosongkan Build Command, isi Publish directory dengan `.`, lalu klik **Deploy site**.
